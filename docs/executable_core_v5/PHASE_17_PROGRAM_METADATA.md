## External boundaries

The result applies to these selected captured/reconstructed images. It does
not prove general JSON parser equivalence or arbitrary program-registry
interpretation. Physical byte capture, filesystem behavior, digest
authenticity, SHA-256, canonical hash-preimage computation, and Python or
physical process execution remain external.

Program keys and feature/tie/freeze digests retain their external cryptographic
origin. V checks the supplied descriptor fields and their typed numerical use;
it does not prove the hash-based procedure that generated grammar parameters
or establish temporal secrecy of public/hidden contexts. The original fixed
grammar and external controller remain fixed. No newly learned or self-hosted
proposer, arbitrary planner/transformer semantics, or fresh live capability
gain is established.

Complete pipeline resource accounting remains open. Reconstruction, byte
capture, JSON parsing, hashing, proof preparation/checking, CPU/accelerator
work, memory, storage, energy, and future active promotion/rollback are
unmeasured in that complete-pipeline sense; they are not treated as zero.
