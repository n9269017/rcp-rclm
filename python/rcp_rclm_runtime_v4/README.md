Runtime v4 mirrors the Gate E formal foundation for deterministic, schedule-free bounded
successor search.

The initial executable surface provides:

```text
canonical route-hint policy with all successful-route answers forbidden
canonical predecessor capability and recursive-productivity frontiers
ordered package-generated attempt records
first-accepted deterministic selection
strict capability-frontier expansion on promotion
recursive-productivity retention
proof-carrying complete bounded-search exhaustion
immutable search-budget accounting
zero manual repair
zero held-out visibility before candidate freeze
Draft 2020-12 schema validation
deterministic promotion and exhaustion references
```

The package is a contract foundation. It does not yet run the active `M4` model or claim a
completed Phase 14 trajectory.
